# My progress in C
# 🔬 hello-c

Un espacio dedicado a mi progreso y aprendizaje del lenguaje C, enfocado en los fundamentos de la ciencia de la computación y la resolución de algoritmos.

## 🎯 Sobre este repositorio
Este repositorio funciona como mi diario de código público. Aquí alojo los ejercicios, retos y proyectos que voy desarrollando, incluyendo mis prácticas del curso CS50x de Harvard. 

El objetivo es documentar mi evolución en la lógica de programación, pasando del uso de librerías de entrenamiento a la escritura de código en C puro estándar.

## 🧠 Conceptos y ejercicios aplicados
Hasta el momento, los programas de este repositorio exploran:
* Estructuras de control y condicionales (`if`, `else`, `switch`).
* Bucles y repetición (`for`, `while`, `do-while`).
* Manejo de memoria y entrada de datos en C estándar (`scanf`, `fgets`, `stdin`).
* Operaciones con arreglos (arrays) y cadenas de texto (`strlen`, `strcspn`).
* Matemáticas básicas y algoritmos de validación (ej: sumadoras, calculadoras, cajeros automáticos).
